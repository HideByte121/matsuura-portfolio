# HAL東京・ゲーム制作ポートフォリオ

HTML・CSS・JavaScriptだけで動く静的サイトです。ビルドやパッケージのインストールは不要です。`index.html` をブラウザーで開くか、任意の静的Webサーバーでフォルダーを配信してください。

## 自己紹介の変更

`index.html` の「氏名を入力」、自己紹介文、学科・学年、使用言語・ツール、興味のある分野を実際の情報に置き換えてください。入力欄は編集用の目印であり、サイト上で入力・保存するフォームではありません。必要に応じて `<title>` と description も変更してください。

## 連絡先の設定

`js/data.js` の `portfolio.email` に公開用メールアドレスを設定します。

```js
const portfolio = { email: '自分のメールアドレス' };
```

空欄または形式が不正な場合は「メールアドレス準備中」と表示します。設定するとアドレスと「メールする」リンクを表示します。リンクは閲覧者のメールアプリを開きます。サイトから直接メールを送信する機能はありません。

## 作品の追加・編集

`js/data.js` の `works` 配列を編集します。現在は5GameBowling、RE：TRACE、暖弾Doneの3件を掲載しています。使わない項目は作品ごと削除でき、追加する場合は1件をコピーして一意の `id` を付けてください。

| 項目 | 内容 |
| --- | --- |
| `id` | URLで使用する固定ID。例：`my-game`。半角英数字とハイフンを使い、重複させないでください。公開後は変更しないでください。 |
| `title` / `summary` | 作品名 / 一覧にも表示する短い説明 |
| `tools` | 使用言語・ツール・技術 |
| `youtubeId` | YouTube動画の11文字のID。例：`YBtmxOndqW8`。空欄では画像を表示 |
| `thumbnail` | 一覧画像のパス。空欄の場合はYouTubeのサムネイルを使用 |
| `images` | 詳細画像のパスの配列。指定した順で縦に表示 |
| `description` | ゲーム概要・遊び方・制作目的 |
| `period` / `teamSize` / `role` | 制作期間 / 制作人数 / 自分の担当 |
| `highlights` | 工夫した点・課題と解決方法 |
| `links` | 動画やGitHubのリンク。不要なら `[]` |

一覧の作品を選ぶと、同じ画面の上に詳細を重ねて表示します。「閉じる」、Escキー、背景クリックで一覧に戻れます。閉じると元のカードへフォーカスが戻ります。直接アクセス用の `work.html?id=my-game` も引き続き利用できます。両方とも同じ作品データと描画処理を使用します。概要・工夫した点の文章では `\n` で改行できます。文字列内のシングルクォートは `\'` と記述してください。

動画は詳細内のYouTubeプレイヤーで再生できます。自動再生は行わず、モーダルを閉じるとプレイヤーを破棄して再生を停止します。動画に画像を添えたい場合は `images` に追加します。再生できない場合は「YouTubeで見る」リンクを使用できます。ローカル確認にはHTTPの静的Webサーバーを使用してください。`file://` で開くとYouTubeが再生を拒否する場合があります。デザインと改修方針は `DESIGN.md` にまとめています。

### 画像・外部リンクの設定例

画像を `assets/img/` に配置して、HTMLからの相対パスを指定します。

```js
thumbnail: 'assets/img/my-game-cover.jpg',
images: ['assets/img/my-game-01.jpg', 'assets/img/my-game-02.jpg'],
links: [
  { label: 'プレイ動画', url: 'https://www.youtube.com/watch?v=実際の動画ID' },
  { label: 'GitHub', url: 'https://github.com/自分のアカウント/リポジトリ名' }
],
```

詳細画像が空の場合は一覧画像を使用し、どちらも空の場合や読み込みに失敗した場合は「画像準備中」を表示します。リンクは実際のURLに置き換えてください。未設定・不正なURLは表示せず、http/httpsのURLのみ新しいタブで開きます。既存のサンプル写真は使用していません。

## 確認手順

- PCとスマートフォンでトップページを開き、作品一覧が2列・1列になることを確認。
- 3件の作品で詳細が重なって表示され、閉じるボタン・Esc・背景クリックで閉じられることを確認。詳細の内部を押しても閉じないことを確認。
- 閉じるとカードへフォーカスが戻り、ページをスクロールできることを確認。再度開いたとき詳細の先頭が見えることを確認。
- 詳細URLへの直接アクセス・再読み込み・一覧への復帰を確認。
- `work.html` と `work.html?id=unknown` で見つからない旨が表示されることを確認。
- 画像やリンクが空でも表示できること、実際に設定した画像・リンクが利用できることを確認。
- Tabキーで移動し、Enterで作品やリンクを開けることを確認。
- 公開用メールを設定したら「メールする」の宛先を確認。

公開時は `index.html`・`work.html`・`css/`・`js/`・使用する `assets/` を同じ構成で配信します。公開・デプロイの設定は含まれていません。
